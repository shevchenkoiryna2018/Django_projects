Локальний запуск
1. Створення віртуального середовища
У кореневій папці репозиторію виконайте:
python -m venv .venv

Активуйте середовище в PowerShell:
.\.venv\Scripts\Activate.ps1

2. Встановлення залежностей
pip install "Django>=6.1,<6.2" Pillow

3. Налаштування змінних середовища
Для безпеки SECRET_KEY не зберігається у вихідному коді.

Згенеруйте власний секретний ключ:
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

Встановіть змінні середовища у PowerShell:
$env:DJANGO_SECRET_KEY = "ваш_згенерований_секретний_ключ"
$env:DJANGO_DEBUG = "True"

4. Запуск проєкту
Перейдіть до папки Django-проєкту:
cd website

Виконайте міграції:
python manage.py migrate

Запустіть сервер:
python manage.py runserver

Відкрийте в браузері:
- Головна сторінка: http://127.0.0.1:8000/
- Адміністративна панель: http://127.0.0.1:8000/admin/

База даних
У репозиторії міститься навчальна база website/db.sqlite3 з прикладами публікацій, категорій, тегів, користувачів і коментарів.

Для доступу до адміністративної панелі можна створити власного суперкористувача:
python manage.py createsuperuser

Примітка
Налаштування DJANGO_SECRET_KEY та DJANGO_DEBUG у PowerShell діють протягом поточної сесії термінала. Після відкриття нового термінала їх потрібно встановити повторно.

Для перевірки проєкту використовуйте власний секретний ключ. Не публікуйте його в GitHub.
